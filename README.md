# Data Alcott Systems — Software Company Website

**Internship task:** Software Company Website  
**Student/task code:** DAS-SW-001  
**Task link:** https://www.freeinternships.in/blog/

## Project overview
A responsive, single-page company website built with HTML, CSS, and vanilla JavaScript. It is designed to introduce a software company, explain services, showcase concept projects, and provide a contact form demo.

## Features
- Responsive desktop and mobile layouts
- Mobile navigation menu
- Home, Services, About, Projects, and Contact sections
- Service cards and concept project previews
- Contact form validation and demo confirmation
- Dynamic copyright year
- Accessible labels and semantic HTML
- No database or JavaScript framework required

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive styling
- `script.js` — mobile menu and contact form interaction

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. For best results, use a local static server or publish the folder using GitHub Pages, Netlify, or Vercel.

## Deployment
### GitHub Pages
1. Create a public repository named `software-company-website`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open repository **Settings → Pages**.
4. Choose deployment from the `main` branch and `/ (root)`, then save.
5. Wait for the published URL and add it to your submission post.
