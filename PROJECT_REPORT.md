# Project Report: Software Company Website

**Project code:** DAS-SW-001  
**Project name:** Data Alcott Systems — Software Company Website  
**Technology:** HTML5, CSS3, JavaScript  
**Database:** Not required

## 1. Objective
The objective of this project is to create a professional and responsive website for a software company. The website communicates the company's services, approach, example project concepts, and a way for prospective customers to make an enquiry.

## 2. Tools and technologies
- HTML5 for semantic page structure and form elements.
- CSS3 for layout, typography, colour, responsive design, and mobile styles.
- Vanilla JavaScript for mobile navigation, dynamic copyright year, and contact-form feedback.
- A modern web browser for testing.
- GitHub Pages, Netlify, or Vercel may be used for static hosting.

## 3. Main modules
1. **Home:** Company introduction, primary call to action, and digital network visual.
2. **Services:** Web development, custom software, and cloud/support service cards.
3. **About:** Company principles and development approach.
4. **Projects:** Two illustrative concept previews.
5. **Contact:** Required fields for name, email, service, and project details.
6. **Responsive navigation:** A menu that opens and closes on smaller screens.

## 4. Implementation
The page is separated into three main files so that structure, presentation, and behaviour are easy to maintain. CSS media queries adapt the layout for mobile screens. JavaScript controls the mobile menu and prevents a demo form submission from reloading the page. A success-style message is displayed to explain that the demo interaction worked locally.

## 5. Testing
- Opened the page in a modern browser.
- Checked that section navigation links point to the correct sections.
- Checked responsive rules for mobile and desktop layouts.
- Checked that the mobile menu can be opened and closed.
- Checked that required form fields are present and the form shows a confirmation message.
- Checked that the page does not depend on a database.

## 6. Conclusion
The project demonstrates a clean, responsive software-company website using only HTML, CSS, and JavaScript. It can be extended with a real form service, additional project case studies, analytics, or a backend if required.

## 7. Limitations
The contact form is for demonstration only; it does not send messages to an email address or store data. The project cards are sample concepts. A live deployment URL and recorded demo must be added after the student publishes and tests the website.
